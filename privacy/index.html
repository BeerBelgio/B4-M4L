PRIVACY

Documentation draft — review before first public release.

WEBSITE

B4~M4L is a static documentation website. The current site code contains no first-party analytics, advertising pixels, forms or user accounts.

HOSTING

The site is intended to be hosted with GitHub Pages. GitHub may process visitor data, including IP addresses, under its own privacy statement. GitHub Privacy Statement

EXTERNAL SERVICES

Links to Shop (Ko-fi), maxforlive.com, BeerBelgio and third-party websites open independent services. Their own privacy policies apply when you visit them. If you follow a link to Apple, see the Apple Privacy Policy.

LANGUAGE PREFERENCE

Your language preference is stored in your browser when supported. A language code may also appear in page URLs to keep it while navigating. B4~M4L does not use this preference for profiling.

HOMEPAGE LAYOUT SESSION

When you edit the homepage, object positions and sizes are stored in sessionStorage for the current browser tab session, when supported. Reset removes this saved layout. These values are not sent to a server, stored in cookies or used for profiling. If browser storage is unavailable, editing still works without reload persistence.

SUPPORT EMAIL

The REPORT AN ISSUE button opens your email application using a prefilled message. B4~M4L does not automatically transmit attachments or diagnostics. Any information you choose to send by email is handled through the email services involved.
