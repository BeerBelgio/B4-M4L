# B4~M4L — 0.13-rc.1

Standalone static documentation website. Open `index.html` for a local preview, or serve this folder with any static HTTP server. No install, build tool or online library is required by the site. Keep the complete assets tree and font licences.

For GitHub Pages, this folder is the site root, including `.nojekyll`. Subdirectory hosting is supported through relative resource paths. This package is a revised 0.13 release candidate; no GitHub deployment is performed by this archive. Product pages describe testing devices; no device download is included.

On supported desktop browsers, drag the top handles or use their arrow keys; Shift increases the step. Resize from the corner. LOCK disables editing, EDIT reenables it, RESET restores the reference composition. Layout is retained for the tab session. Touch and narrow displays use a fixed layout. HELP supports five languages; German, Spanish and French translations are automatic editorial drafts.

The Privacy page is part of the public website. Its support-email retention description must reflect the operator’s actual handling practice.

Canonical site: https://beerbelgio.github.io/b4-m4l/

The sitemap lists all four public pages, including Privacy. No domain-wide robots file is included; indexing may be coordinated from the BeerBelgio hub.

See `CHANGELOG.md` for the 0.13 changes. Authoring and sitemap regeneration tools remain in the separate ARCHIVE; they are not needed to host PUBLIC.
